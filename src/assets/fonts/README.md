# Plus Jakarta Sans

Official variable WOFF2 files from Google Fonts, downloaded on 2026-11-16:

- Latin: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2
- Latin extended: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko40yyygA.woff2

The original binaries support weights 200–800. The interface declares 400–800,
including native variable weights 700, 750 and 800. Portuguese characters are
included. Files are served locally with `font-display: swap`.
